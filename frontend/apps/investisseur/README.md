# ZIRA INVEST — Investor Portal (`apps/investisseur`)

The **Investor Portal** empowers individual and institutional investors to discover high-impact ventures, analyze company metrics, execute investment tickets, complete identity verification (KYC), and track their portfolio performance.

## Key Features

- **Authentication**: Email or Username + Password login and registration.
- **Project Discovery**: Filter by sector (Fintech, Agritech, Tech, Health, Energy, Education), search, and campaign progress trackers.
- **Investment Flow**: Equity calculators, investment ticket submission, and portfolio tracking.
- **4-Step KYC Workflow**: Identity document upload, verification selfies, proof of address, and compliance status tracking.
- **User Profile**: Account details with `@username`, public bio, and investment preferences.

## Development

```bash
npm run dev --workspace=apps/investisseur
```
