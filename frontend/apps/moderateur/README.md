# ZIRA INVEST — Moderation & Compliance Console (`apps/moderateur`)

The **Moderation & Compliance Console** is a specialized back-office interface for compliance officers, legal auditors, and platform administrators.

## Key Features

- **Security & RBAC**: Restricted access for verified compliance officers.
- **KYC Review Queue**: Inspection of submitted identity documents, proof of address, and liveness verification with single-click approve or reject actions.
- **Campaign Auditing**: Reviewing founder submissions for regulatory and disclosure compliance before publishing them live.
- **User Governance**: Account status controls, user directory inspection, and audit logs.

## Development

```bash
npm run dev --workspace=apps/moderateur
```
