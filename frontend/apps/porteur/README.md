# ZIRA INVEST — Project Owner Portal (`apps/porteur`)

The **Project Owner Portal** provides founders and entrepreneurs with end-to-end tooling to launch fundraising campaigns, structure cap tables, upload pitch materials, and engage with verified investors.

## Key Features

- **Authentication**: Secure founder sign-in with Email or Username + Password.
- **Campaign Creation**: Multi-step project wizard capturing sector, market, funding target, equity percentage, pitch deck, and founding team.
- **Campaign Management**: Real-time funding progress, investor cap table overview, and campaign updates.
- **Company Profile**: Public startup identity with founder `@username`, company bio, and verification badges.

## Development

```bash
npm run dev --workspace=apps/porteur
```
